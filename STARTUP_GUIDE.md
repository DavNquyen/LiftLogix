# LiftLogix - Quick Start Guide

## 🚀 First Time Setup

### 1. Start Infrastructure (Docker)
```bash
cd ops
docker compose up -d
```

This starts:
- PostgreSQL (port 5432)
- Redis (port 6379)

### 2. Backend Setup

```bash
# Activate virtual environment
source .venv/bin/activate  # macOS/Linux
# or: .venv\Scripts\activate  # Windows

# Navigate to API directory
cd api

# Run database migrations
alembic upgrade head

# Seed exercises and demo user (one-time)
python seed.py

# Start the API server
uvicorn app.main:app --reload --port 8000
```

The backend will be available at: **http://localhost:8000**

### 3. Frontend Setup (New Terminal)

```bash
cd web

# Install dependencies (if not already done)
npm install

# Start dev server
npm run dev
```

The frontend will be available at: **http://localhost:3000** (or 3001 if 3000 is in use)

## 🚨 Troubleshooting

### "Cannot connect to Docker daemon"
- Start Docker Desktop
- Or run: `docker ps` to check status

### "Port already in use"
- Backend (8000): `lsof -ti:8000 | xargs kill -9`
- Frontend (3000): `lsof -ti:3000 | xargs kill -9`

### "Failed to fetch" (Frontend)
- Ensure backend is running on port 8000
- Check CORS settings in `/api/app/config.py`

### "Database connection error"
- Verify PostgreSQL is running: `docker ps`
- Check credentials in `.env`
- Run migrations: `alembic upgrade head`

### "Module not found" (Python)
- Activate venv: `source .venv/bin/activate`
- Install deps: `pip install -r api/requirements.txt`
